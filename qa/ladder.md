# The ambition ladder

What the users in QA runs ask for, from simple to the goal: an articulated, tendon-driven
hand that works and is fully sourced. Each run picks a level and a project of its own in it
(not one from an earlier run); a level is passed when runs in it end with what the user
wanted, in the viewer, saved, without a fight.

| level | what | e.g. |
|---|---|---|
| L1 | one part, printable | phone stand, cable clip, wall hook, enclosure with lid, tube clamp |
| L2 | a part family and its paperwork | variants side by side, a change request ("M5 instead of M4"), BOM, dimensioned drawing, supplier quotes and costs, a design review |
| L3 | mechanisms that move | pin hinge, spur gear pair (real involutes, center distance), planetary stage, four-bar linkage, cam and follower, with a motion study and clearance checks |
| L4 | assemblies with purchased parts | servo bracket for a real servo (dimensions from its datasheet), 608 bearing housing, lead-screw linear stage; BOM with prices and links |
| L5 | one tendon-driven finger | three phalanges on pin joints, tendon channels, return elastics, a servo spool; range of motion, tendon excursion per joint, grip force estimate, sourced parts |
| L6 | the hand | four fingers and an opposable thumb, palm, wrist, forearm actuator pack, tendon routing through the wrist; motion study, interference check, sourced BOM, print settings, assembly guide |

The user may go up a level within a run when things go well ("nice, now make it move").
